Проект кликера
1. Скачиваете файл
2. Распаковывайте архив в папку Документы на компьютере. 
3. Запускаете проект в Godot

Добавление новых версий
После изменения основного проекта (Старую версию сохраните/продублируйте у себя), залейте на гитхаб новую версию, подписав её номером. 
Изначальная версия - 1.0. Значит следующая будет 2.0. 
Таким образом в репозитории будут все версии проекта. Если изменения незначительны (Подпишите её наподобие - 2.1), данная версия будет удалена, как появится более актуальная.
